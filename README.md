# kicad-runtime-build

Builds a relocatable runtime of [Backplane KiCad](https://github.com/i2cjak/Backplane_KiCad) (GPL-3.0) at a pinned commit, bundled with the official KiCad symbol, footprint, 3D model and template libraries, and uploads it as a GitHub Actions artifact.

Run the **Backplane KiCad runtimes** workflow and choose a platform. The archive carries the source commit, a source tarball and the licenses of everything it includes.
